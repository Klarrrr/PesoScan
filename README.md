# PesoScan

A YOLO26-based mobile app for Philippine coin and banknote detection
and value calculation using deep learning.

## Features
- Real-time detection of coins and bills with running total
- Offline scanning (on-device model)
- Scan history and statistics
- Email-based login with 2-step verification

## Tech stack
Flutter · Dart · Provider · SQLite · Supabase · YOLO26 (TFLite)

## Getting started
1. Install Flutter and run `flutter doctor`
2. Clone the repo, then run `flutter pub get`
3. Run `flutter run`
